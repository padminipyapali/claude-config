02Side Channels Into the Loop

PR Review Feedback

CodeRabbit or human leaves review comments. Skill validates each comment, fixes issues, and extracts durable learnings into shared knowledge.

/review-fix <pr>

Mid-Session Capture

Pattern discovered during work that isn't tied to a PR. Capture immediately to the matching topic file without waiting for review.

04What's Automated vs. Manual

Action Trigger Mechanism
Load knowledge at plan time Automatic CLAUDE.md directive → reads INDEX.md + stack-matched topics
Capture learnings at PR time Automatic Adversarial review learning gate (hook blocks push without it)
Update project docs Automatic CLAUDE.md Living Documentation directive
Inject knowledge into new project Automatic /project-setup reads topics matching declared stack

Fix PR review comments Manual /review-fix <pr> — validates, fixes, captures learnings
Full consolidation sweep Manual /consolidate-learnings — periodic safety net
Ad-hoc pattern capture Manual /capture-learning — mid-session

07Known Gaps & Future Opportunities

No effectiveness measurement

No A/B test has compared agent performance with vs. without the knowledge base. "Compounding intelligence" is a narrative, not a measured outcome.

Deferred — run minimal test when 5th project starts

No decision/strategic memory

Knowledge captures technical patterns but not product judgment ("Padmini prefers X approach") or strategic memory ("we tried Z and it failed because...").

Deferred — add once system value is proven

Consumption is unverified

No way to confirm agents actually read and applied knowledge files. The CLAUDE.md directive says "read them" but there's no mechanical enforcement.

Deferred — no good enforcement mechanism exists yet

PR rejection feedback is manual

When you reject a PR or say "wrong approach," that judgment doesn't automatically flow into knowledge. The /review-fix skill helps, but requires manual invocation.

Deferred — add PR outcome logging (5 lines) when ready
