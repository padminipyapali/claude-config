## Workflow Preferences

### Review-Fix: Critically Evaluate Before Fixing
- **Don't blindly fix all automated reviewer comments.** When running /review-fix, first evaluate whether each comment is actually correct. CodeRabbit frequently flags non-issues — nitpicks on docs wording, overly conservative null guards on typed fields, style suggestions that don't improve the code. Categorize each as **must fix** (real bug, security, correctness), **should fix** (valid improvement), or **disagree** (explain why and skip).
