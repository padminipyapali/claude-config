Cross-Project Knowledge System

How Claude agents learn from every project and get smarter over time.

How It Works

Plan
Agent loads relevant topic files from shared knowledge
automatic — CLAUDE.md directive
Build
Implementation informed by all sibling project learnings
automatic — patterns already loaded
Review
Adversarial review runs mechanical checklist
automatic — hook blocks push without it
Capture
New learnings written to shared knowledge topic files
automatic — review step 7 (learning gate)
Key principle: Knowledge is organized by topic, not by project. A new React + PostgreSQL project automatically gets all React and database learnings from every previous project — no manual cross-pollination needed.

Where Everything Lives

~/.claude/
  knowledge/ ← shared knowledge (by topic, all projects)
    INDEX.md ← topic list + stack matching guide
    typescript-patterns.md
    react-patterns.md
    llm-integration.md
    database-patterns.md
    adversarial-review.md
    ...
  CLAUDE.md ← global rules (concise, loaded every session)
  commands/ ← /consolidate-learnings, /capture-learning, etc.
  projects/*/memory/ ← per-project context (project-specific)

<project>/.claude/
  skills/adversarial-review/ ← references shared checklist
  hooks/ ← blocks push without review

Automation vs. Manual

Action Trigger How
Load knowledge when planning Automatic CLAUDE.md directive → reads INDEX.md + matching topics
Capture learnings at PR time Automatic Adversarial review step 7 (hook-enforced, can't skip)
Update project docs Automatic CLAUDE.md Living Documentation directive
Inject knowledge into new project Automatic /project-setup reads topics matching declared stack
Full consolidation sweep Manual (safety net) /consolidate-learnings — catches anything missed
Quick ad-hoc capture Manual (convenience) /capture-learning — mid-session pattern capture

The Feedback Loop

Plan (reads knowledge)
↓
Build (applies patterns)
↓
Review (mechanical checklist)
↓
Capture (writes new learnings to knowledge/)
↓
Next project plans → reads updated knowledge → cycle repeats

Every PR makes the next project better.
