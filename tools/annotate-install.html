Claude Annotator

Drag the button below to your bookmarks bar. Click it on any page to add annotations and send feedback to Claude.

✏ Annotate
Requires the annotation server running on localhost:9876. Claude starts this automatically when needed.

Setup

1
Drag the button above to your bookmarks bar
2
Navigate to any page you want to annotate
3
Click ✏ Annotate in your bookmarks bar
4
Click elements, add comments, then click Send to Claude

Works on

HTML mockups created by Claude
Dev server pages (localhost)
Live production pages
Any web page you want to give feedback on
